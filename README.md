# Backend API för Todo-plattform

Detta är backend-delen för min Todo-applikation, byggd med ASP.NET Core WebAPI och SQLite.

## Så här startar du projektet:

1. Öppna en terminal i projektmappen.
2. Installera eventuella beroenden (om det behövs) och återställ databasen:
   ```bash
   dotnet restore
   dotnet ef database update
